## 一、产品定位

减肥监控台 Pro 不是「给你一个固定计划让你照做」的工具，而是：

- **AI 个性化生成**：根据你的身体数据、作息、运动偏好，自动计算 BMR、TDEE、建议摄入、阶段目标和训练计划
- **可视化编排器**：时间表、训练计划、阶段目标全都可以自己改
- **饮食热量追踪**：内置常见中餐食物热量库，记录每日饮食并自动计算热量
- **数据主权在你**：所有记录默认存在手机/平板浏览器本地
- **高度可扩展**：支持导入/导出 JSON、加载模板、自定义指标和食物
- **移动优先**：添加到 iPhone/iPad 主屏幕后，体验接近原生 App

## 二、安全与隐私说明

### 我们做了什么

| 项目 | 处理方式 |
|---|---|
| 数据存储 | 浏览器 `localStorage`，不上传任何服务器 |
| 网络请求 | 除了加载本应用文件外，不发任何数据到外部 |
| 第三方依赖 | 无 CDN、无统计、无广告 |
| 账号系统 | 不需要注册、登录、手机号、邮箱 |
| 可选加密 | 支持用 Web Crypto API 对数据本地加密 |

### 你需要知道的限制

- **本地加密是可选的**，默认关闭；开启后忘记密码无法恢复数据。
- **所有数据绑定在你的浏览器里**，如果你清除 Safari 网站数据或卸载主屏幕图标，数据可能丢失，建议定期导出 JSON 备份。
- 如果部署在 **GitHub Public 仓库**，应用代码是公开的，但你的个人数据（体重、记录、饮食）仍只存在你自己的设备上，不会公开。

## 四、部署方式：GitHub Pages（推荐）

### 4.1 注册 GitHub 账号

1. 打开 [https://github.com](https://github.com)
2. 点击右上角 **Sign up**
3. 输入邮箱、设置密码、创建用户名
4. 按提示完成验证

### 4.2 创建仓库

1. 登录后点击右上角 **+** → **New repository**
2. **Repository name** 填：`weight-loss-pwa-pro`
3. 选择 **Public**（公开）
4. 点击 **Create repository**

### 4.3 上传文件

1. 在仓库页点击 **Add file** → **Upload files**
2. 将 `index.html`、`manifest.json`、`service-worker.js`、`icon.svg` 以及 `examples` 文件夹拖入上传区
3. 等全部上传完成后，点击底部 **Commit changes**

### 4.4 开启 GitHub Pages

1. 点击仓库顶部 **Settings**
2. 左侧菜单点击 **Pages**
3. **Branch** 选择 `main`，点击 **Save**
4. 等待 1–3 分钟，页面会显示绿色访问链接：
   ```
   https://你的用户名.github.io/weight-loss-pwa-pro/
   ```
5. 这个链接就是你的减肥监控台 Pro 访问地址

> 如果希望代码不公开，可以将仓库设为 **Private**，然后同样在 Settings → Pages 中开启。

## 五、其他部署方式

### 方案 A：Vercel

1. 访问 [https://vercel.com](https://vercel.com)，用 GitHub 账号登录
2. 点击 **Add New Project**
3. 导入 `weight-loss-pwa-pro` 仓库
4. 点击 **Deploy**
5. 获得 `xxx.vercel.app` 访问链接

### 方案 B：Netlify

1. 访问 [https://netlify.com](https://netlify.com)
2. 将项目文件夹拖拽到 Netlify 首页上传区域
3. 自动部署并生成访问链接

### 方案 C：本地使用（不部署）

可以直接用浏览器打开 `index.html` 查看界面，但以下功能受限：

- 添加到主屏幕体验不完整
- 数据可能无法持久保存（iOS Safari 对 `file://` 限制 localStorage）
- 无法使用 Service Worker 离线缓存
- 本地加密需要 HTTPS（部分浏览器在 `file://` 下不可用 Web Crypto）

## 七、iOS 日历提醒导入

由于 iOS 对网页后台通知限制严格，**锁屏提醒通过 iOS 系统日历实现**。

### 生成日历文件

1. 打开应用，进入 **设置** 页
2. 点击 **生成并下载 iOS 日历提醒**
3. 系统会下载一个 `减肥计划提醒.ics` 文件

### 导入到 iPhone/iPad 日历

1. 在 Safari 中打开下载的文件，或在“文件”App 中点击它
2. iOS 会提示“添加全部 X 个日程”，选择 **添加全部**
3. 可以选择创建一个新的日历（如“减肥计划提醒”），方便以后管理
4. 之后每天到点会收到系统锁屏通知

### 修改提醒后重新导入

如果你在应用里修改了时间表，需要：

1. 重新生成并下载 `.ics`
2. 打开 iOS 日历，删除之前导入的“减肥计划提醒”日历
3. 重新导入新的 `.ics` 文件

## 八、首次使用：设置向导

首次打开应用时，会进入 **设置向导**，你需要回答以下问题：

### 第 1 步：基础信息

- 称呼（可选）
- 性别
- 出生年份
- 身高

### 第 2 步：身体数据

- 当前体重
- 目标体重
- 计划周期（周）

系统会根据这些数据计算：

- BMI
- 基础代谢（BMR）
- 每日总消耗（TDEE）
- 建议每日摄入热量
- 每周建议减重速度

如果你的目标减重速度超过安全范围（约体重的 1%/周），系统会提示风险，但仍会按你的要求生成计划。

### 第 3 步：女性指标（仅女性用户显示，可选）

- 胸围、腰围、臀围

### 第 4 步：作息安排

- 起床时间
- 入睡时间
- 单次运动时长

### 第 5 步：运动偏好

- 选择日常会做的运动：游泳、骑车、跑步、力量训练、拳击、瑜伽、徒步等
- 每周运动天数
- 通常运动时间

### 第 6 步：方案确认

系统展示完整的个性化方案：

- 建议日摄入
- 阶段目标
- 每周训练安排

点击“完成”后，应用会自动生成：

- 阶段目标
- 每周训练计划
- 每日时间表

## 九、功能使用指南

### 9.1 底部导航

| 入口 | 功能 |
|---|---|
| 📅 今日 | 当前状态、倒计时、时间轴、训练计时器 |
| 📊 数据 | 记录体重/BMI/腰围/体脂/三围、趋势图、阶段目标 |
| 🍱 饮食 | 记录每日饮食、热量统计、饮食参考 |
| 📝 编排 | 编辑今日日程、保存日程模板、加载模板 |
| 🏋️ 训练 | 编辑每周训练计划、切换/保存训练模板 |
| ⚙️ 设置 | 个人资料、安全加密、主题、备份恢复、重新运行向导 |

### 9.2 今日页

- **当前应进行**：根据当前时间自动判断你应该做什么
- **下一个提醒**：距离下一个日程事件还有多久
- **睡眠倒计时**：距离目标入睡时间的倒计时
- **今日时间轴**：全天事件可视化展示，当前进行中的事件会高亮
- **训练计时器**：开始运动前点击“开始”，结束后点击“暂停/重置”

### 9.3 数据页

#### 记录身体数据

1. 选择指标（体重/腰围/体脂率/胸围/臀围）
2. 输入数值
3. 选择日期（默认今天）
4. 可填写备注
5. 点击 **记录**

#### BMI 与体型

- 根据最新体重和身高自动计算 BMI
- 显示中国标准：肥胖（≥28）、超重（24–28）、正常（<24）
- 显示基础代谢和每日总消耗

#### 建议摄入

基于 BMR、TDEE 和目标减重速度，自动计算建议每日摄入热量。

#### 趋势图

- 下拉选择指标，用 Canvas 绘制折线图
- 至少需要 2 个数据点才会显示趋势

#### 阶段目标

- 向导自动生成多阶段目标
- 可点击右上角 **添加** 增加更多阶段
- 每个阶段显示起始体重、目标体重、截止日期、完成进度

### 9.4 饮食页

#### 记录饮食

1. 在早餐/午餐/晚餐/加餐栏目下点击 **+ 添加**
2. 选择食物分类：主食、肉蛋奶豆、蔬菜、水果、菜品、零食饮品
3. 选择具体食物，输入份数
4. 点击 **添加**

#### 热量统计

顶部显示：

- 已摄入热量
- 建议摄入热量
- 剩余热量

#### 自定义食物

如果食物库中没有你要找的食物：

1. 点击食物选择器底部的 **+ 自定义食物**
2. 填写名称、单位、热量、蛋白质、碳水、脂肪
3. 保存后即可使用

#### 饮食原则

提供每餐搭配建议和食堂红绿灯参考。

### 9.5 编排页（日程编辑）

#### 修改事件

1. 点击事件右侧 **编辑**
2. 修改名称、时间、时长、类型、描述、提醒设置
3. 点击 **保存**

#### 添加事件

1. 点击右上角 **+ 事件**
2. 填写信息，点击 **保存**

#### 删除事件

- 点击事件右侧 **删除**，确认后移除

#### 日程模板

- **应用模板**：点击模板卡片的“应用”，当前日程会被替换
- **保存为模板**：点击“将当前日程保存为模板”，方便以后复用

### 9.6 训练页（每周训练编辑）

#### 编辑某一天

1. 在 7 天网格中点击某一天
2. 选择训练类型（游泳/骑车/跑步/力量/拳击等）
3. 填写活动名称、时长、距离/量、备注
4. 点击 **保存**

#### 切换训练计划

- 顶部下拉框可以选择已保存的训练计划

#### 训练模板

- **应用模板**：用示例模板替换当前计划
- **保存为模板**：把当前计划保存为自己的模板

### 9.7 重新运行向导

在 **设置** 页点击 **重新运行设置向导**，可以修改身体数据、作息和运动偏好，系统会重新生成目标和计划。已有体重记录会保留。

## 十、数据备份与迁移

### 导出数据

1. 进入 **设置** 页
2. 点击 **导出所有数据（JSON）**
3. 会下载一个类似 `减肥监控台备份_2026-08-04.json` 的文件
4. 建议保存到 iCloud Drive、电脑或邮件中

### 导入数据

1. 点击 **导入数据（JSON）**
2. 选择之前导出的备份文件
3. 确认覆盖后，所有数据（包括日程、训练、目标、记录、饮食）会恢复

### 换设备迁移

1. 旧设备：导出 JSON 备份
2. 将 JSON 文件发送/传输到新设备
3. 新设备：安装应用后，导入 JSON 备份

## 十一、本地加密说明

### 开启加密

1. 进入 **设置** → **本地安全**
2. 打开 **启用本地密码加密** 开关
3. 输入至少 6 位密码
4. 点击 **设置密码**

### 效果

- 体重、目标、日程、训练计划、记录、饮食等数据会用 AES-GCM 算法加密
- 下次打开应用需要输入密码才能使用
- 密码只保存在你的大脑里，任何人和系统都无法重置

### 关闭加密

1. 关闭 **启用本地密码加密** 开关
2. 数据会以明文形式重新保存

### 注意事项

- **忘记密码 = 数据永久丢失**，务必导出 JSON 备份
- 加密功能需要在 HTTPS 环境下使用（GitHub Pages/Vercel 都支持）
- `file://` 本地打开时，部分浏览器可能不支持 Web Crypto API

## 十二、自定义与扩展

### 12.1 使用示例模板

`examples` 文件夹中提供了 3 种预设模板：

- **游泳减脂模板**：适合大体重、关节保护优先
- **骑行有氧模板**：低冲击有氧为主
- **混合训练模板**：游泳+骑车+力量+拳击轮换

这些模板可以作为手动创建日程和训练计划的参考。

### 12.2 修改默认配色

打开 `index.html`，在 `<style>` 的 `:root` 中修改颜色变量：

```css
:root {
  --primary: #0ea5e9;        /* 主题色 */
  --success: #22c55e;        /* 成功/运动色 */
  --warning: #f59e0b;        /* 饮食/提醒色 */
  --danger: #ef4444;         /* 警告/红色 */
}
```

### 12.3 添加自定义训练类型

打开 `index.html`，找到 `typeIcons` 和 `typeLabels`，添加新的类型：

```javascript
const typeIcons = { ..., dance: '💃' };
const typeLabels = { ..., dance: '舞蹈' };
```

## 十三、常见问题

### Q1：iPhone 添加到主屏幕后打不开或 404？

- 确保 `service-worker.js` 和 `manifest.json` 中的路径是相对路径 `./`，不是根路径 `/`
- 删除旧主屏幕图标，清除 Safari 网站数据，重新添加
- 参考 GitHub 仓库中已修复的版本

### Q2：体重记录无法保存？

- 如果只打开本地 `index.html` 文件，iOS Safari 可能限制 `localStorage`
- 请部署到 GitHub Pages 后再使用

### Q3：为什么收不到应用内通知？

- iOS 网页通知需要用户授权，且应用必须处于打开状态
- 建议使用 **iOS 日历提醒导入** 获得锁屏通知

### Q4：深色模式在哪里切换？

- **设置** → **界面** → **深色模式** 开关

### Q5：如何重新开始？

- **设置** → **危险区域** → **清空所有本地数据**
- 或者卸载主屏幕图标后重新添加

### Q6：向导生成的目标太激进怎么办？

- 在向导第 2 步延长计划周期
- 或在设置页重新运行向导，调整目标体重和周期
- 系统会始终给出风险提示

### Q7：可以同时多端同步吗？

- 不支持自动云端同步
- 可以通过 **导出/导入 JSON** 在设备之间手动迁移
